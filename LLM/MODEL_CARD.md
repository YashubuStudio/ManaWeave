# RuneLM Pilot — 実測モデルカード

## 出自と構成

このモデルはManaWeaveのために原著コードで構築し、ランダム初期化から学習した自己回帰Transformerです。既存モデルのパラメータ、外部の文章データ、他のLLMからの蒸留データは使っていません。独自実装とは数式まで新発明したという意味ではなく、一般的なTransformer演算をこの用途のために実装したものです。テンソル計算・自動微分にはPyTorch 2.5.1+cpuを使用しました。

| 項目 | 実測・設定値 |
|---|---|
| パラメータ数 | 247,776 |
| Transformer層 | 2 |
| 隠れ幅 / ヘッド数 | 96 / 4 |
| 文脈長 / 語彙数 | 96 / 171 |
| 位置表現 | 学習可能な絶対位置埋め込み |
| FFN | 幅384、ReLU |
| 出力 | 操作・範囲・出力・素材・終了の最大5トークン |
| 重み | FP32、992,352バイトの独自形式 |
| 学習用例数 | 22,729 |
| 最終学習 | 2,000ステップ、バッチ64、seed 731 |
| 学習時間 | 約183秒、この検証用CPU環境のみ |
| モデルSHA-256 | `98dfde27d4ac3c6e19863036b8c3469f04e72932475c2385f127eb0d12974931` |

約0.000248Bの実験用小型モデルです。0.1Bモデルを完成・学習済みとする表示はしていません。96,758,144パラメータの拡張用構成は別ファイルで提供しますが、その学習済み重みはありません。

## 生のモデル評価

学習文と完全一致する文を含まない1,158件の開発用評価集合で、出力文法を制約した自己回帰デコードを実行しました。結果はIRの全フィールド一致で判定しています。

| 区分 | 正解 / 評価数 | 完全一致率 |
|---|---:|---:|
| 全体 | 914 / 1,158 | 78.93% |
| 日本語 | 575 / 579 | 99.31% |
| 英語 | 339 / 579 | 58.55% |
| 学習集合のサンプル | 256 / 256 | 100% |

これはテンプレートを分離した狭い合成データでの結果です。日本語全般の理解精度を示す数字ではありません。英語は語順が変わると大きく崩れます。高い出力確率でも誤答が発生したため、確信度だけで実行を許可していません。

この評価集合は開発時に一度観測し、その後学習側の丁寧表現や句読点の形式を増やしました。したがって**開発用評価**であり、未観測の最終検収セットではありません。前回の結果は `experiments/` に残しています。

## ゲームに接続したC#経路の評価

最終重みを凍結した後、Unityでも使用する同じC# `MagicParser` を.NET 8で動かし、入力ガード、実モデル推論、出力の整合性検証を通した結果です。語彙、出力値、意味の不一致があれば拒否し、LLMの答えを別の術式へ自動修正しません。

| 経路 | 評価対象 | 正しく受理 | 誤った受理 | 陽性例の受理率 |
|---|---|---:|---:|---:|
| 学習型RuneLM＋ガード | 開発集合：正例1,152・負例6 | 902 | 0 | 78.30% |
| 直接構成WSP＋ガード | 同じ開発集合 | 1,152 | 0 | 100% |
| 学習型RuneLM＋ガード | 凍結後の新しい手動例：正例24・負例24 | 22 | 0 | 91.67% |
| 直接構成WSP＋ガード | 同じ新しい手動例 | 16 | 0 | 66.67% |

両経路とも、各集合の負例をすべて拒否しました。新しい手動例はモデル凍結後に作成し、学習・開発集合との文字列重複を排除しています。どちらのモデルにも評価後の学習やルール調整はしていません。これも48件の小さい診断例であり、実プレイヤーの任意入力に対する誤りゼロを保証しません。

WSPは有限の語彙と規則から重みを直接構成した別方式です。この比較から「学習不要で任意のLLMを作れる」とは結論できません。

## PythonとC#の数値一致

7つのプロンプトについて、PyTorchの全語彙ロジットと独自C#推論を照合しました。最大絶対誤差は **0.00000381469727** で、許容値0.003以内でした。`parity_fixture.json` のモデルハッシュも一致しています。

この結果はC#に同じモデルが実装されていることの確認です。Unity Editorでのシーン再生やビルドの検証とは別です。

## 利用上の境界

- 生成した術式は必ずプレビューします。装備・発動は独立したプレイヤー操作です。
- 数値、否定、条件、例外、複数操作など表現できない意味は拒否します。
- 魔力の生成、消費、安定化、共鳴、熱の増減を計算するのは世界法則エンジンです。
- モデルは対象IDや世界状態を直接変更しません。
- 確定入力が必要な場合は、DSLまたはホットバーのプリセットを使用します。
- 研究用の対話、複雑な文章、音声認識、画像の魔法陣認識、自由な新原理の創造は対象外です。

再現用の数値と全予測は `training_report.json`、`evaluation_report.json`、`acceptance_report.json` および対応するJSONLに保存されています。
