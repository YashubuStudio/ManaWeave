# ManaWeave：抵抗型の世界法則

改訂：2026-11-05-mana-resistance

この文書は現在のCore実装を説明します。旧版の「小規模は安定化・大規模は共鳴増幅」は廃止しました。旧仕様は `History/WORLD_LAWS_PRE_RESISTANCE.md` に記録しています。

## 基本原則

| 世界の設定 | 現在の実装 |
|---|---|
| 無から空間魔力が発生する | 全セルの `AmbientMana` へ自然生成。吸収は前提にしない |
| 物質が魔力を吸収・保有する | 空気を含む11物質に吸収率と容量を設定 |
| 命令のない魔力は抵抗する | 熱変化は規模・正負を問わず基準状態へ戻す。自然な増幅は行わない |
| 大気の抵抗が強い | 気体の熱変化への抵抗係数を8倍に設定。空気の有効熱容量も見直し |
| 直接指定した範囲には魔法が作用する | 加熱・冷却は領域全体へ指定Jを適用し、その領域だけ有限時間、抵抗を弱める |
| 指定範囲外へ効力が広がりにくい | 隣接セル間の熱移送に空間魔力の抵抗を適用。伝播によって制御領域が自動で拡大することはない |
| 事象化した魔力は無へ帰る | 作用に使用した量を空間・物質・人体の保有量から引き、消費へ記録 |
| 魔力による物理エネルギーの増減を認める | 熱の消去・寒冷の打消しを、通常の伝熱と区別して記録 |

今回の一般化方針は、命令のない魔力をすべての現象に対する抵抗へ統一することです。**現在、独立した抵抗ソルバーとして実装している対象は熱変化と熱伝播です。** 燃焼・相変化・セル単位の水/蒸気移動は既存の粗い物理モデルを使用します。運動量、圧力、電気、重力、生命などの一般ソルバーは未実装です。全現象への拡張設計は `OPEN_MAGIC_PROGRAMS.md` にあります。

## 世界状態と空気の変更

標準世界は48 × 24 × 48セル、シード731。1セルを1 mとして表示します。物質量はゲーム用の有効質量で、全物質を実密度の1 m³として再現するモデルではありません。

| セルの値 | 意味 |
|---|---|
| `Material`, `Mass` | 物質ID、有効質量kg |
| `Energy` | 物質モデルの基準からの熱エネルギー・エンタルピーJ。倍精度（double）で保持 |
| `AmbientMana` | その空間にある魔力MU |
| `StoredMana`, `Fuel` | 物質に保有する魔力、木材の残存燃料 |
| `ThermalCommandUntil` | その空間セルに対する熱的な指示の有効期限。シミュレーション秒 |

空気の有効質量は**0.020 kgから1.2 kg**へ変更しました。比熱1005 J/(kg·K)は同じなので、1セルの熱容量は**20.1 J/Kから1206 J/K、60倍**です。120 kJを7個の空気セルへ加えた直後の温度上昇は、抵抗や伝熱を適用する前で旧約852.88°C、新約14.21°Cです。魔法の総Jを黙って減らすことで調整していません。

物質の移送では質量・熱・保有魔力・燃料が移動します。空間魔力と熱指示の有効期限は座標に残ります。建築・掘削や実験の準備で `SetMaterial` により物質を置換した場合、そのセルの古い熱指示は解除します。

温度は `WorldState.Temperature(index)` から求めます。エネルギーは20°Cからの差分ではありません。偏差は `Energy - MaterialCatalog.RoomEnergy(cell)` です。通常物質の温度は絶対零度−273.15°Cを下回らないモデルです。表示値だけを都合のよい範囲に丸める処理ではありません。

|---|---:|---|
| `ManaGeneration` | 0.42 | 低密度時の自然生成MU/セル/秒 |
| `AmbientSaturation` | 28 | 自然生成が止まる空間魔力の基準 |
| `ManaDiffusion` | 0.8 | 隣接する空間魔力の交換係数 |
| `AbsorptionScale` | 1 | 物質吸収速度の倍率 |
| `ThermalDiffusion` | 2 | 通常の伝熱係数の倍率 |
| `NaturalCoupling` | 0.32 | 熱偏差を戻す基本の抵抗率 |
| `GasResistanceMultiplier` | 8 | 空気・蒸気の抵抗率の倍率 |
| `DirectedResistanceMultiplier` | 0.08 | 有効な熱指示があるセルでの抵抗倍率 |
| `DirectedThermalSeconds` | 1秒 | 熱魔法の局所制御が有効なシミュレーション時間 |

`CriticalEnergy` と `CoherenceSlope` は旧コードとのソース互換のため残していますが、現在の計算で使用しません。値を変えても自然増幅は起きません。

人体の初期魔力は1800 MUです。回復では近傍セルの空間魔力を実際に減らします。自然生成は `G × dt × max(0, 1 - AmbientMana / saturation)`。飽和を超えた空間魔力を自動で削除しません。

## 熱変化に対する抵抗

基準エネルギーを `Eref`、現在の偏差を `dE = E - Eref` とします。現在の基準は一律20°Cで、水系は20°Cの液体水のエンタルピーが基準です。季節・局所気候の平衡を推定するモデルではありません。

```text
密度 = 空間魔力 + 0.2 × 利用可能な保有魔力
抵抗率 = 基本率 × 気体倍率 × 密度/(密度+5) × 指示中の倍率
要求する打消し量 = abs(dE) × (1 - exp(-抵抗率 × dt))
実際の打消し量 <= 要求量、利用できる魔力×J/MU、abs(dE)
```

方向は必ず基準側です。高温では熱を除去し、寒冷では熱を加えます。指数型の係数は0〜1で、時間刻みや現象規模が増えても符号を反転させません。熱量と伝熱の演算は倍精度で行い、魔力の実際の減少量に収まる作用だけを確定します。魔力予算を超える変化や基準の飛び越しを防ぎます。

空間魔力を優先し、不足する場合は有効化された保有魔力も使います。各抵抗処理の空間アクセスは `min(1, 8×dt)`、自然抵抗の保有アクセスは `min(1, 0.7×dt)` の割合を上限にします。魔力がなければ魔法的な抵抗は起きません。大きな偏差を打ち消す途中で魔力が尽きれば、抵抗は弱まります。

`StabilizedJoules` は打ち消した偏差の大きさ、`NaturalEnergyJoules` は符号付きの正味のエネルギー変化です。寒冷の打消しでも魔力を消費します。`AmplifiedJoules` は互換用の欄ですが、現在の実行で増加させる経路はありません。

## 指定範囲と空間減衰

熱魔法は指定した球の中だけへ総熱量を適用します。成功後、対象セルの `ThermalCommandUntil` を現在のシミュレーション秒＋1秒にします。この期間だけ熱抵抗率を0.08倍にします。これは新しい熱を継続供給する処理ではありません。温度や熱量を永久固定する処理でもありません。

範囲外へ熱が伝わっても、そのセルへ命令期限は発行しません。気体や液体が移動しても、指示範囲は物質に付いて移動しません。再度の明示的な熱魔法は、そのときに選択した領域の期限を更新します。時刻は実時間ではなくシミュレーション時間なので、一時停止中は期限も進みません。

隣接ペアの通常の熱移送量を先に計算し、両側の空間魔力密度と指示の状態から `exp(-SpatialResistance × opacity)` を通過率とします。ただし阻止量は利用可能な空間魔力で支払える範囲に限ります。

各セルに共通の消費可能量を用意し、処理する辺ごとに減らします。6方向が同じ魔力を重複して使うことはありません。阻止された熱は元の場所に残り、通過する熱だけが移送されます。したがって、この阻止処理自体は世界の総熱量を増減させません。消費魔力と `SuppressedTransportJoules` へ阻止した移送量を記録します。

指定地点への直接作用と、指定範囲外へ二次的に伝わる現象を分けています。今回、術者から照準点へ至る経路を飛翔する火球のソルバーは追加していません。

## 更新順序と再現性

`Step(dt)` は0秒より大きく1秒以下。最大0.05秒のサブステップに分けます。Runtimeの通常更新は0.1秒です。熱指示の有効性は各サブステップの開始時点で判定するため、期限の切替には最大0.05秒の離散化幅があります。

1. 空間魔力を生成。
2. 空間魔力を対称に拡散。
3. 熱伝導の要求を計算し、伝播抵抗の魔力を確保して通過分を移送。
4. 熱偏差に対する自然抵抗を適用。
5. 物質へ魔力を吸収。
6. 有限燃料の燃焼、相変化、水・蒸気の移送。
7. 人体へ近傍魔力を吸収。
8. 時刻を更新し、必要な描画差分を通知。

熱抵抗を受けた後でも、燃焼など別の実在する熱源がある場合は温度が上がり得ます。自然魔力による増幅を廃止することは、燃料からの熱放出も禁止することを意味しません。同一ランタイムの状態・入力列に対する再現性を検証し、異なるCPU間のビット一致は保証しません。

## 魔法命令と収支

| 命令 | 効果 | 消費・条件 |
|---|---|---|
| 加熱 | 範囲全体へ指定の総Jを追加 | 熱容量に比例配分。`総J/1600 + 2 + セル数×0.08` MU |
| 冷却 | 範囲全体から指定Jを上限に除去 | 現存する熱量に比例配分。0未満にせず実除去量で課金 |
| 掘削 | 有体物を空気へ置換 | `2 + 3×変更セル数` MU。外部素材・熱収支を記録 |
| 建築 | 空気・蒸気の場所に指定物質を配置 | `2 + 5×変更セル数` MU。外部素材・熱収支を記録 |
| 充填 | 人体から物質の空き容量へ魔力を移す | 移送したMU＋制御用2 MU |
| 錬成 | 条件を満たす鉄を魔導合金へ変換 | 各セル250°C以上・保有6 MU以上。人体10 MU、保有6 MU/セル |

球の半径は1〜5セル。半径1は中心と6近傍の最大7セルです。Coreの1回の熱操作上限は8 MJ、充填は10,000 MU。入力DSLには別途現在の上限があります。世界側は物質・人体魔力・数値を検査してから確定し、失敗時は熱指示の期限も含めて途中変更しません。

```text
全魔力 = 初期魔力 + GeneratedMana + ExperimentMana - ManifestedMana
全熱量 = 初期熱量 + NaturalEnergyJoules + SpellJoules
       + CombustionJoules + ReactionJoules + SandboxEnergyJoules
全質量 = 初期質量 + SandboxMassKg
```

吸収や充填は内部移送です。伝播の抑制は魔力を消費しますが、抑制Jを総熱量の増減へ二重加算しません。物質変更で保有できなくなる魔力は空間へ戻します。

水の融解・蒸発は潜熱を含む連続エンタルピー、燃焼は有限のFuelを消費する近似、水と蒸気の移動はセル単位の入れ替えです。精密な流体力学・化学反応網は含みません。

準備時に投入する物質・熱・魔力は外部実験供給として記録します。実験の準備をプレイヤーの通常魔法の成果として扱いません。

## 保存と旧版の移行

v2は熱エネルギーと熱指示期限を倍精度で保存し、1セル当たり33 bytesです。保存サイズの上限は72 MiBです。v1のファイルも読み込め、旧単精度エネルギーを倍精度へ変換します。旧版の空気のうち、質量が旧標準の `0.020f` と厳密に等しいセルだけを移行します。基準20°Cからの偏差エネルギーを維持し、空気の質量と基準エネルギーを新しい値へ補正します。ほかの物質とカスタム質量は変えません。このため対象の高温空気の温度表示は下がり、低温空気は基準に近づきます。これはバランス変更によるデータ移行で、ゲーム内で魔法を使った物理作用として記録しません。

補正量は `MigrationEnergyJoules` と `MigrationMassKg`、説明は `MigrationNotice` に保持します。読込だけで元ファイルを書き換えません。v2で保存し直した後は再移行しません。旧コードはv2を読めないので、更新前の保存データを残してください。

保存はSHA-256による破損検出、値とサイズの検査、一時ファイルからの置換を行います。累積のセッション統計やConfigは保存せず、読込後の現在状態を新しい集計基準にします。
