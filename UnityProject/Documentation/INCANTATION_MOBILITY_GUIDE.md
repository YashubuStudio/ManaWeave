# ManaWeave：錬金の加熱・自由な詠唱・物質移動

改訂：2026-11-05-incantation-mobility / Unity 6.3 LTS

## この版の目的

前版では、標準の120 kJが周囲の空気へも分配され、直接指示の有効時間も短いため、通常の操作で錬成条件の250℃へ届きにくい状態でした。この版は、対象一点・素材の選別・目標温度・明示した保護時間を導入し、加熱から充填、錬成までを通常の魔法で行えるようにします。自然な共鳴増幅は戻しません。

日本語の詠唱では、従来の文体に加えて数値と単位、対象、温度、保護時間、移動方向・距離を扱います。修辞を含む呼びかけと、実際に実行する指示を区別します。未対応の効果、否定、条件分岐、矛盾する数値などを、意味を捨てて成功扱いにはしません。

## 最初に錬成する

最初はシミュレーションを1倍速にします。保護時間はシミュレーション時間で、倍速時には実時間の操作猶予が短くなります。

1. ワールド内の鉄へ照準を合わせます。右の観測欄で素材が「鉄」であることを確認します。
2. **1：加熱** を装備して左クリックします。新しい基本術式は対象1セルを350℃へ加熱し、10秒間、指示範囲の自然な熱抵抗を軽減し、周囲への熱漏れを抑えます。
3. 照準を鉄に合わせたまま、**5：魔力充填** を装備して左クリックします。
4. **6：錬成** を装備して左クリックします。250℃以上・保有魔力6 MU以上の鉄が魔導合金へ変わります。

F8の実験用加熱や魔力注入を使わずに実行できます。対象に十分な温度・保有魔力がなければ、日本語の理由を表示して中止します。発動前に表示される消費魔力は照準先の現在状態による見積りです。

## 詠唱の例

**Tab → 魔法工房 → 詠唱解析 → 詠唱を解析 → 内容を確認 → この術式を装備して戻る → 左クリック** の順です。解析・装備だけでは発動しません。

### 温度を指定して鉄を加熱

```text
照準先の鉄を350℃まで加熱し、10秒間保護せよ。
```

文体を長くした例です。目標とする効果は同じです。

```text
紅蓮を統べる精霊よ、我が呼び声に応えよ。
照準先の鉄を三百五十度まで熱し、
十秒間その熱を守れ。
```

「350℃まで」は現在温度から必要な熱を計算する指定です。「10秒間保護」は指示範囲への制御が有効な時間です。**温度を10秒間完全固定したり、熱を自動で補充したりする指定ではありません。**

### 熱量を指定

```text
対象一点に200キロジュールの熱を与えよ。
```

同じ量は `200kJ`、`0.2MJ`、`200000J` と表記できます。熱量は選択範囲全体の合計です。温度上昇量は対象の質量、比熱、相変化によって変わります。全角数字と漢数字も解析対象に含めています。

### 魔力を充填

```text
巡る魔力よ、照準先の鉄へ10MUを充填せよ。
```

充填する10 MUは術者から物質へ移送する魔力です。詠唱割引が適用されるのは制御に使う消費分です。移送する元本を割り引いて魔力を増やす処理はありません。

### 物質を移動

```text
対象を上へ3メートル移動させよ。
```

基本術式の **7：物質移動** でも利用できます。照準先を起点とする範囲内の物質を、指定した方向へ1〜8セル移動します。1セルを1 mとして表示します。

上・下・東西南北に加え、視点を基準とする前・後・左・右を扱います。視点基準の移動は水平の格子方向へ変換し、画面に実際の移動先を示します。途中に対象外の固体・液体がある場合や、世界の端を越える場合は中止します。移動元と移動先が重なる範囲も、物質を複製せずに扱います。

移動はボクセル物質の格子単位の移送です。プレイヤーの瞬間移動、速度を持つ飛翔体、連続的な剛体運動はこの機能には含みません。

## 消費魔力と詠唱の長さ

消費量は事象の規模を基準に計算し、詠唱による効率を適用します。

- 加熱・冷却：実際に操作する熱量、範囲、保護時間。
- 物質移動：移動する質量、距離、経路の空間魔力による抵抗。
- 建築・掘削：変更するセル数。
- 錬成：変換するセル数と、素材に保有された反応用魔力。
- 充填：実際に移す魔力と制御費。

長く変化のある詠唱ほど、事象化・制御に必要な魔力が少なくなります。文字列を正規化し、文字の隣接する組み合わせの種類から「有効詠唱長」を計算します。空白・句読点・数字の追加は数えず、同じ句の反復だけでは大きく増えません。

```text
詠唱倍率 = max(0.4, 1 / (1 + 有効詠唱長 / 80))
有効詠唱長の上限 = 120
```

最大で、割引対象の消費が通常の40%になります。魔力充填の移送元本と、錬成で素材から消費する6 MU/セルは割引対象外です。数値指定DSLと基本術式には、詠唱文による割引はありません。

解析後に工房で温度・範囲などの意味を手動変更した場合、古い文章による割引を解除します。詠唱の効果を適用するには、変更後の意味を文章に反映して再解析してください。

## 導入

1. Playを停止し、Unity Editorを閉じます。
2. プロジェクトと旧セーブをバックアップします。独自に編集した同名ファイルも上書きされるため、変更がある場合は差分を確認して取り込んでください。
3. `ManaWeave_Incantation_Movement_Update.zip` を解凍します。
4. ZIPの **Assets** を既存プロジェクトの **Assets** へ結合し、同名ファイルと `.meta` を上書きします。`Assets/Assets` の二重階層を作らないでください。
5. Unityのコンパイル終了後、**Tools → ManaWeave → 世界法則と魔法を検証** を実行します。
6. SandboxをPlayし、新しい基本術式を選びます。旧セーブから装備を復元した場合は、1などの数字キーで新しい基本術式へ切り替えてください。

Package Managerの「ディスクから追加」用パッケージではありません。新規導入には完全版を展開し、Unity Hubへ `ManaWeave/UnityProject` を追加します。

## 解析モデルと確認範囲

この版では既存のWSPとRuneLMの重みを維持し、数値・単位・対象・温度・移動などを構造化する解析層を拡張しています。画面は解析経路と、実際に解釈した術式を表示します。任意の日本語や未実装の物理現象を実行できる汎用LLMではありません。

確認結果は `INCANTATION_VERIFICATION.json` と `VERIFICATION.md`、法則と制約は `WORLD_LAWS.md` に収録しています。Unity Editorを実行できない環境での検査のため、実際の描画・IME・Playerビルド・FPSは未確認です。
